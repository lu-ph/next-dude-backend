## 1. 为什么真人老师比 ChatGPT “更好理解”？

在开发针对中学生的学习 Agent 时，观察到真人老师的讲解往往比 AI 更易懂。研究表明，这并非偶然，而是因为真人老师在教学中运用了 AI 往往缺失的学科教学知识（Pedagogical Content Knowledge, PCK）。

真人网课老师的策略：

1. 知识组织：采用叙事性结构，将知识点串联成有逻辑、有节奏的故事。
2. 解释工具：大量使用类比和隐喻，将抽象概念锚定在学生已有的知识上。
3. 认知负荷：懂得分块，根据学生的实时反馈调整信息密度。
4. 互动模式：采用苏格拉底式提问，引导学生自己思考出答案。

典型 ChatGPT 输出的局限：

1. 知识组织：倾向于列表式输出，知识点之间缺乏有机联系。
2. 解释工具：解释往往过于严谨、学术化，缺乏具象化的参照物。
3. 认知负荷：一次性输出大量信息，容易导致学生的认知过载。
4. 互动模式：直接给出答案，剥夺了学生的思考过程。

## 2. 人是如何学习的？

要设计最优的 AI 学习 Agent，必须遵循人类认知的基本规律。

## 2.1 认知负荷理论

人类的工作记忆容量有限（约 7±2 个信息单元）。

- 设计建议：Agent 每次对话只讲解一个知识点。
- 最优解：采用“微课”模式，将长篇大论拆解为短小精悍的互动对话。

## 2.2 建构主义学习观

学习不是被动接收信息，而是学生基于原有知识经验主动建构意义的过程。

- 最优解：通过关联旧知识来引入新知识，建立知识网络而非孤岛。

## 3. 学习效果最优解：实证有效的策略

研究公认的两种最有效的学习方法是：

1. 主动回忆

- 原理：提取信息的动作本身就是学习。
- AI 实现：Agent 不应只讲课，而应频繁进行“随堂小测”，考察之前讲过的内容。

2. 间隔重复

- 原理：在遗忘曲线的关键点重新复习。

## 4. AI 学习的最优解：如何构建“名师级”Agent？

基于上述理论，建议 Agent 采用以下设计架构：

1. 从“告知者”转向“引导者”（Socratic Agent）

- 不要直接给出定义，而是通过一系列启发式问题引导学生。

2. 支架式教学（Scaffolding）

- 根据学生的掌握程度，动态调整支持力度。
- 当学生遇到困难时，先给提示，再给步骤，最后才给答案。

3. 闭环反馈（Feedback Loop）

- 不仅判断对错，更要分析错误原因。
- AI 应该能识别出学生是“概念理解错误”还是“计算粗心”，并给出针对性的纠错指导。

## 5. 总结与建议

要让 Agent 像真人老师，核心不在于知识的“深度”，而在于“转化”的艺术。建议在 Prompt 工程中加入以下约束：

1. 叙事框架：遵循“提出疑问 → 探索尝试 → 引入概念 → 巩固练习”的教学闭环。
